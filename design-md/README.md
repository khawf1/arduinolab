# DESIGN.md reference library

84 DESIGN.md files from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(commit `3b60532`, MIT — see `LICENSE`). Each folder describes one site's design language
(colors, type, spacing, components) in a form AI agents can follow.

To adopt one, copy it to the project root:

```sh
cp design-md/<name>/DESIGN.md ./DESIGN.md
```
